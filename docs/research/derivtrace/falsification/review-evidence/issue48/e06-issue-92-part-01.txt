## Purpose

Retire the former TURNLOCK formal-assurance construction lineage from the active
repository path while preserving the current Product Intent, canonical
terminology, all 42 stable invariants, later independent product corrections,
and retained Proto-Ring repository governance.

ADR-059, `Retire formal-assurance architecture and reopen post-invariant
design`, is the decision this migration must materialize. It is not cited here
as an already published source.

The examined baseline is
[`b1b8902cb2be879f3930c2730002a1ea5e4e1f02`](https://github.com/fanilosendrison/turnlock-rust/tree/b1b8902cb2be879f3930c2730002a1ea5e4e1f02).

## Scope

- Preserve a byte-exact archive of the complete examined Git source tree and a
  bounded public GitHub work-history capture made before retirement mutations.
- Remove `formal/**`, `docs/formal/**`, the dedicated formal traceability
  checker, its renderer, and its test module from the active path.
- Supersede only ADR-041 through ADR-049 and ADR-053 through ADR-057, while
  preserving every historical ADR body and recording the transition in ADR-059.
- Amend the active methodology through the two exact specification edits and
  the bounded repository-governance adaptations required by ADR-059.
- Preserve Repository Governance Model v2, all eight capabilities, all eleven
  immutable Governance Binding Registry bindings, the exact native Proto-Ring
  provider pin, generic governance checks, ADR integrity, terminology
  governance, reference protection, CI, and canonical publication.
- Retire the selected GitHub work route without rewriting historical success or
  treating abandonment as delivery.

## Exclusions

- No replacement assurance architecture, claim layer, Gate sequence, formal
  language, model topology, campaign runner, workflow runtime, or TURNLOCK
  implementation is selected or created.
- No archived source is executed or adopted as active instruction.
- No formal Gate or product-verification result is claimed.
- No private Scope content is copied, and Scope does not become TURNLOCK
  authority.
- No unrelated product, dependency, provider, protection, or Project taxonomy
  change is authorized.
