## Problem

Qualified subject: [#70](https://github.com/fanilosendrison/turnlock-rust/issues/70), which records a bounded, source-bound `CONFIRMED` semantic-correspondence / coverage weakness (subject to required independent review). `TL-CLAIM-011` currently requires normal completion to return to the exact immediate caller and authorize only the appropriate continuation, but the normative consequence `normal completion of an admitted workflow-declared invocation => the preserved post-call continuation becomes eligible according to enclosing topology` is not independently represented by the required assurance claims. `authorization` must not be assumed equivalent to `eligibility`.

This Issue owns **a later, independently reviewable correction of formal assurance decomposition and declared coverage**; it does not retroactively authorize changes in #70.

## Current authoritative boundary

The **product behavior is already accepted**. The returned immediate caller context and its preserved post-call continuation are distinct; declared invocation return positively establishes post-call eligibility when the enclosing topology allows it. Agent-selected invocations instead resume the appropriate **same agent region**, which must not be silently completed or bypassed. The only/appropriate-continuation restriction is **local to that return**, not a rule stopping admissible concurrent siblings. `TL-INV-042` / `TL-CLAIM-083` impose conditional liveness only **after** eligibility.

This is `no-normative-impact` corrective assurance work representing an obligation `derived-from-existing-authority`. No new Product Intent / invariant / product ADR is authorized.

## Counterexample and negative controls that must survive review

- **CE (must be excluded)**: accepted + normal + workflow-declared + topology permits post-call + exact caller restored + correct continuation authorized + incorrect continuation unauthorized + preserved return relation, but `postcall_eligible=false`. The new claim must exclude it **without** assuming `authorized => eligible`.
- **Positive ordinary declared return (must remain admitted)**: same as CE except `postcall_eligible=true`.
- **Main-agent-selected nested return (must remain admitted)**: normal return resumes the same main-agent region, with enclosing workflow post-agent continuation still unavailable until that region completes.
- **Independent-agent-selected nested return (must remain admitted)**: normal return resumes the same independent agent and lineage, not the parent workflow or session main-agent.
- **Independent parallel sibling (must remain admitted)**: declaration-local suspension/return and post-call eligibility do not automatically stop a concurrent sibling whose progression is allowed by topology.
- **Rejected pre-acceptance call (must not fake normal success)**: no callee occurrence exists and no successful post-call continuation is released.
- **Join / liveness**: post-join eligibility obeys that join's distinct constraints; `TL-CLAIM-083` alone does not establish initial eligibility, and the new safety claim does not promise termination of callees or scheduler-level eventual progress.
